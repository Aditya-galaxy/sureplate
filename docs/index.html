How it works

  1. The maker mints one passport NFT per unit and locks NEAR inside it as that unit's bond.
  2. Anyone can file a security advisory against the product line by staking NEAR. That starts the patch clock.
  3. Patch published in time: nothing is owed. Deadline missed: the current NFT owner collects 10% / 25% / 50% of the bond (low / high / critical).
  4. Bogus advisory: the maker disputes, an arbiter rules, the loser pays.
  5. After the support period, the maker takes back whatever is left. Sell the device and the passport, bond and claim rights go with it.
